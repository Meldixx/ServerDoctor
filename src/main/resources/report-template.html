How to interpret these results

The health index uses configurable thresholds and is not a performance benchmark. TPS is a rolling average and MSPT represents the Paper-reported measurement. A dense chunk is not necessarily an expensive chunk. JVM GC totals are cumulative. This document sends no network requests. For actual plugin CPU attribution, profile with spark while the lag is happening.
